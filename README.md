# Business Use Cases — Codex Skill

Пакет инструкций для инвентаризации, описания и пересмотра бизнес-сценариев по **фактам реализации**. Сценарии на русском, основная диаграмма Mermaid `flowchart`, минимум технических деталей. Внутри нет требований к языку программирования, архитектуре и структуре исходного кода.

## Установка

Расположи **всю папку** `business-use-cases` в одном из каталогов, которые Codex сканирует:

- Во все проекты конкретного пользователя: `~/.agents/skills/business-use-cases/`.
- Только в одном репозитории: `.agents/skills/business-use-cases/` от корня репозитория.

После копирования можно явно вызвать `$business-use-cases` в Codex CLI/IDE. Без явного вызова скилл подбирается по описанию задачи. Если он не появился, перезапусти Codex.

## Примеры запросов

- `Используй $business-use-cases. Найди значимые бизнес-сценарии проекта и составь каталог, без подробных документов.`
- `Используй $business-use-cases. Документируй сквозной сценарий отмены заказа: фактические шаги, состояния сущностей, исключения и Mermaid.`
- `Используй $business-use-cases. Сверь документацию возврата с текущим кодом и тестами и исправь только фактические расхождения.`

По умолчанию документы создаются в `docs/use-cases/`, но существующие соглашения проекта имеют приоритет. Скилл **не** меняет `AGENTS.md`, не рефакторит код и не вводит автоматическое наблюдение за изменениями.

## Комплект

- `SKILL.md` — короткие рабочие инструкции и условия активации.
- `references/modeling-guidelines.md` — границы Use Cases, правила диаграмм, проверка точности.
- `assets/use-case-template.md` — **полностью заполненный** нейтральный пример структуры.
- `agents/openai.yaml` — необязательные метаданные для интерфейса.
- `evals/` — проверочные кейсы и исторические примеры; Codex не обязан загружать их при обычной работе.

## Проверка

`python3 evals/check_package.py` проверяет состав пакета, метаданные и структурные ограничения (полный YAML — если установлен PyYAML). Для поведенческой оценки запусти запросы из `evals/cases.yaml` в тестовом репозитории и оцени по `evals/README.md`. Статическая проверка не заменяет выполнение Codex на реальном коде.
